    TRANSLATION

    Get a free DeepL key

    DeepL translates recipes into the language Goodstock is set to. The free plan allows 500,000 characters a month; a recipe is about 1,000 to 3,000.

    1. Open the DeepL API pageGo to deepl.com/pro-api and choose DeepL API Free (not the paid Pro plan, and not the regular DeepL app subscription).
    2. Create your accountSign up with your email. DeepL may ask for a card to check you are a real person; the Free plan is not charged.
    3. Copy your keyIn your account, open API Keys and copy the key. Free keys end in :fx.
    4. Paste it in GoodstockBack in Settings → Translation (DeepL), paste the key and tap Save & test. You should see how many characters you have used this month.
    5. Translate a recipeOpen any recipe in another language and tap Translate to … next to Edit. It translates into the language Goodstock is set to.

    The key is saved on the Goodstock server (or, in the phone app, on the phone) and is never shown again. Recipe text is sent to DeepL to be translated.
