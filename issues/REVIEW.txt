12. looks off checkbox way to large .png: Shopping → From recipes ("Pick the recipes" dialog)
---------------------------------------------------------------------------------------------
What's wrong
  In the recipe picker (from v4.5.3) every row is broken. The tick box is a huge grey square (about 50px) with
  the recipe name squeezed under it. The "×" sits on its own line above a full-width "1" field. The search box
  is a plain grey browser box with square corners. It looks worst in dark mode, where the native checkbox is grey.
  Cause: CSS specificity. The general dialog rules win over the picker's own:
    - styles.css:379 .app-dialog label:not(.ingredient-check) { display: block; font-size: 11px … } beats
      .recipe-shopping-pick / .recipe-shopping-amount { display: flex … } (styles.css:315, 317). The labels stack
      instead of sitting in a row, and the name is small grey 11px text.
    - styles.css:380 .app-dialog label > input { width: 100%; height: 45px; margin-top: 7px … } beats
      .recipe-shopping-pick > input { width: 22px; height: 22px } and .recipe-shopping-amount > input
      { width: 64px } (styles.css:316, 318). The checkbox and the number field are stretched.
    - #recipe-shopping-search (index.html:283) is not inside a <label>, so none of the dialog input styles reach
      it.
    - The "Leave out what is in stock" checkbox under the list (index.html:285) has the same problem.
  The page test (tests/page/recipe-shopping.js) only checks behaviour, so this got through.

Fix
  - styles.css: put .app-dialog in front of the picker rules (.app-dialog label.recipe-shopping-pick,
    .app-dialog label.recipe-shopping-amount, … > input) so they win. Rows become checkbox · name … × [ 1 ] on
    one line, the name in normal ink at 13-14px, and the amount field 64px wide and 38px high.
  - Tick boxes: use the app's own green box (.custom-check, styles.css:342, as on the shopping list and in the
    cook dialog) instead of the native checkbox. Same size and look in light and dark mode, and the Chrome 81
    tablet draws it the same.
  - Search box: give #recipe-shopping-search the dialog field look (45px, 1px border, 5px radius, white / dark
    background, styles.css:380 and the dark rule at :669), or put it in a visually labelled field.
  - Same treatment for "Leave out what is in stock".
  - Phone width: the row keeps the name on the left and the amount on the right; a long name wraps instead of
    pushing the field off.
  - Test: extend tests/page/recipe-shopping.js to check that the tick box is at most 26px wide, that a row is
    one line (under 60px high), and that the search field has a border radius.
  - CHECK: the green custom tick box (matches the rest of the app) or just a normal-sized native checkbox
    (smaller change)? I'd use the custom box.
